# Regaleria  VIOLET 
La pagina web se basa en una regalería, una tienda dedicada en donde se venden objetos de tipo regalo, accesorios, perfumes u objetos decorativos para uso personal

# Repositorio
dentro repositorio trabajamos cada colaborador o miembro en su propia rama en donde al terminar una parte de su trabajo o tarea se subirá con un pull request a una sola rama la cual se llama (Develop) en donde se une todo lo hecho en las distintas ramas
